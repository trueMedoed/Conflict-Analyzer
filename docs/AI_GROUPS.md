# Группы ИИ — фоновые патрули

[Сводка](../snapshots/1.8.0.13/worlds/CTI_Campaign_HQC_Eden/AI/Summary.md). Первый охват — 299 компонентов SCR_AmbientPatrolSpawnPointComponent HQC Everon 1.8.0.13. Все находятся в subscene 1, но отбор не ограничивает номер subscene.

## Данные и выбор

World source читается из завершённой диагностики, а каталог отдельно через ME_CA_AICatalogProbe: Resource.Load FIA_Campaign.conf, унаследованные m_aEntityCatalogs / m_aMultiLists / m_aEntities, SCR_EntityCatalogAmbientPatrolData. Состав — разрешённое m_aUnitPrefabSlots префаба. Бойцы не создаются, мир не открывается и не сохраняется при чтении каталога. Не копировать широкие дампы, журналы и код игры в Git.

Код установленной игры (пути и SHA в JSON): SCR_AmbientPatrolSpawnPointComponent.Update выбирает первый совпавший тип. GetRandomPrefabByProbability выбирает единый случайный порог от 0 до максимума, затем случайный элемент среди прошедших. Это не независимая вероятность спавна и не обычное суммирование весов. 11 случайных точек имеют исходный TEAM_SENTRY, но это поле игнорируется: фиксированных TEAM_SENTRY 74, а не 85.

SCR_AmbientPatrolSystem.ProcessSpawnpoint проверяет состояние, наблюдателей, расстояние и бюджет активации. m_iRespawnPeriod — секунды; 0 означает no respawn по таймеру. Фактическое количество ИИ не измерялось. Значения spawn/despawn distance сохраняются как overrides: система может ограничивать их своими пределами, отрицательные значения означают использование системных настроек.

350 м по X/Z, включительно до округления. Города, деревни, поселения, острова, холмы — первый приоритет; Name Generic — второй. Внутри приоритета выбирается ближайшая подпись, при равенстве — ID. Все кандидаты сохранены. Пруды, реки, озёра исключены. Координаты Markdown округлены до 3 знаков, JSON хранит исходные.

## Запуск

В отдельном Workbench-процессе с проектом addon: -wbModule=WorldEditor -run -exitAfterInit -plugin=ME_CA_AICatalogProbe. Использовать журнал именно этого процесса и убедиться в BEGIN / COMPLETE и совпадении версии. Пример чтения файлов сверялся с [официальным API FileIO](https://community.bistudio.com/wikidata/external-data/arma-reforger/EnfusionScriptAPIPublic/interfaceFileIO.html); игровые значения получены из установленной версии, не из веб-таблиц.

Затем tools/New-AIGroupsReport.ps1: DiagnosticsPath, CatalogLogPath, LocationsPath, SourceCodeDirectory, OutputDirectory, RevisionId. SourceCodeDirectory содержит проверенные scripts/Game/Components/Locations/SCR_AmbientPatrolSpawnPointComponent.c и scripts/Game/Systems/SCR_AmbientPatrolSystem.c только для фиксации происхождения. Выходной каталог должен быть новым. Канонический результат — AI/Groups.json; Markdown строится из нормализованных записей.

В этой первой версии генератор поддерживает FIA и 9 проверенных enum-типов; другая фракция, неизвестное поле, неполный журнал или смешение версий приводят к ошибке. Источники мира и локаций ранее собраны; каталог префабов прочитан 13.10.2026. Это не новое чтение всех объектов мира.

## Сверка и ограничения

Размеры девяти групп совпали с прежней AI-Group-Types.md, но вычислены заново из ресурсов. Проверена точка Airport 4953.892 28.380 11979.468: FIRETEAM, 5 слотов. Старые таблицы содержат локальные координаты отдельных вложенных точек и значения probability of presence, не представленные текущими полями компонента; они не переносятся в новый снимок.

1128–1194 — сумма одной потенциальной группы на каждую включённую точку. Варианты случайной точки не суммируются одновременно. Это не верхняя граница ИИ всех систем мира. Отсутствие размещённых SCR_AIGroup в диагностике не исключает динамические группы; защитники баз и прочие системы остаются вне текущего охвата. Вооружение по именам персонажей не предполагается.

## Вооружение

ME_CA_AIWeaponsProbe читает фиксированный список 17 персонажей текущего каталога через Resource.Load и IEntitySource.GetComponent. Запуск в отдельном процессе: -wbModule=WorldEditor -run -exitAfterInit -plugin=ME_CA_AIWeaponsProbe; рабочий каталог процесса должен быть каталогом Workbench (steam_appid.txt). Требуется работающий Steam. Проба не создаёт сущности и не сохраняет сцену.

Передайте WeaponsLogPath в New-AIGroupsReport.ps1 вместе с прежними аргументами: Add-AIWeaponsReport.ps1 проверяет BEGIN/COMPLETE, версию, ошибки чтения и точное покрытие персонажей каталога; добавляет Weapons.json, ссылку в data.json и таблицы типов. Для другого каталога обновите список ресурсов пробы; отсутствие персонажа должно завершать нормализацию ошибкой. Выход создаётся в новой ревизии.

В сумме оружия учитывается каждый непустой CharacterWeaponSlotComponent.WeaponTemplate каждого бойца. CharacterGrenadeSlotComponent показывает только тип, без числа гранат. InitialInventoryItems сохраняются только для Prefabs/Weapons, как отдельные конфигурационные записи; они не прибавляются к оружейным слотам. Полный боезапас, содержимое одежды и runtime-изменения не измерены. Названия префабов преобразуются в читаемые обозначения; неизвестные сохраняют имя ресурса.

## Медицинское снаряжение ИИ — r0049

На всех 9 страницах типов добавлены морфий, бинты (FieldDressing) и жгуты (Tourniquet): количество на одного бойца и итог группы с учётом повторных слотов. В начале страниц указана цель — отладка состава снаряжения и поиск отсутствующих предметов. Medical.json сохраняет каждое совпадение в унаследованном InitialInventoryItems[].PrefabsToSpawn[], индекс записи и prefab. Использовано уже завершённое чтение 17 персонажей Workbench 1.8.0.13 с сохранением SHA и даты, новое чтение мира не выполнялось. Ноль означает отсутствие в этом списке; вложенное содержимое одежды/рюкзаков и фактический runtime-инвентарь не проверялись. Количество точек, оружие, данные припасов и старые ревизии сохранены.

New-AIGroupsReport.ps1 при WeaponsLogPath также вызывает Add-AIMedicalReport.ps1. Тот проверяет версию, завершённость и покрытие персонажей; один ресурс в разрешённом массиве считается одним предметом. Одинаковые предметы не дедуплицируются. Сумма группы умножает количество на число слотов персонажа. Medical.json добавлен в индекс data.json.


## Боезапас фоновых групп — r0050

Все 9 страниц типов дополнены магазинами/коробками, патронами в них и ручными/дымовыми гранатами: итоги группы и на бойца. Отдельно указаны запасные магазины, вставленные магазины, фактическое наполнение / вместимость и патроны в патронниках. Ammunition.json — отдельный runtime-опыт 1.8.0.13: 17 префабов создавались по одному в изолированном процессе HQC Eden без MissionHeader; чтение через 500 мс, затем тестовый персонаж удалялся. Это не проверка активированных патрулей. GetItems + GetMagazine объединяются по идентичности сущности; гранатные шаблоны повторно не прибавляются. Сигнальные средства и выстрелы RPG исключены из ручных гранат и патронов стрелкового оружия, исходные предметы и muzzles остаются в JSON. Сохранён SHA журнала. Исходные списки медицинского снаряжения, оружие, 299 точек, припасы и прошлые ревизии не меняются.

Параметр InventoryRuntimeLogPath у New-AIGroupsReport.ps1 включает Add-AIAmmunitionReport.ps1. Требуется отдельный завершённый журнал [ME_CA_AI_INV] с совпадающей версией и точным покрытием персонажей. Экспериментальный скрипт и запуск — docs/experiments/ai-inventory; его не включать в обычный addon.
