# Conflict Analyzer — черновик Workshop (русский перевод)

Служебная заметка: неопубликованный черновик для внутренней сверки. Диагностика source реализована; полный игровой отчёт ещё планируется. Блоки Summary и Description используют обычный текст для копирования. По умолчанию для Workshop предназначена английская версия; обновлять обе версии нужно вместе после проверки.

## Summary

Помощник Workbench для исследования мира Conflict. Первый прототип выгружает частичную диагностику источников; полные отчёты по ИИ, припасам, стартовым базам и машинам ещё разрабатываются.

## Description

Conflict Analyzer помогает автору сценария исследовать конфигурацию мира Conflict. Он развивается в инструмент сбора понятных отчётов, чтобы не вести все таблицы вручную.

Текущий статус
• Команда диагностики World Editor читает выбранные source-сущности, поля компонентов, слои, ссылки на prefab и мировые позиции в частичный JSON.
• Проверена на CTI_Campaign_HQC_Eden.ent в Arma Reforger / Workbench 1.8.0.13.
• Полные игровые отчёты и сравнение версий ещё не реализованы. Это неопубликованный прототип.

Планируемые возможности
• Точки появления ИИ, типы групп, фракция, состав и число бойцов, с отдельным отображением случайных вариантов и вероятностей появления.
• Точки с припасами и число хранилищ, начальные припасы, вместимость, количество и интервал пополнения.
• Кандидаты стартовых HQ, их местоположение, исходные припасы и настройки их генерации.
• Точки появления машин, местоположение, допустимые варианты техники и доступные настройки спавна или повторного появления.
• Читаемый отчёт с источниками данных и предупреждениями о неполной информации.

Текущее использование диагностики
1. Открыть addon-проект в Arma Reforger Workbench.
2. Открыть сохранённый мир Conflict в World Editor.
3. Выполнить Export world source diagnostics в [ME] Conflict Analyzer / Diagnostics. В репозитории также описан проверенный CLI-путь через журнал Workbench.

Диагностика читает текущее состояние редактора и не сохраняет исходный мир. Файловая выгрузка использует отдельный каталог; прямой экспорт через FileIO ещё требует интерактивной проверки.

Ограничения
• Одного чтения .ent недостаточно: нужно разрешать связанные слои, родительские миры, prefab и конфигурационные ресурсы.
• Настроенные кандидаты и максимальные возможные количества не гарантируют конкретный спавн в игровой сессии.
• Значения зависят от версии мира и игры. Недоступные ресурсы должны обозначаться как неизвестные, а не ноль.
• Объектные конфиги и каталоги фракций этот диагностический прототип пока не разрешает. Найденные компоненты не являются игровыми итогами или числом бойцов.
• Runtime-диагностика и интерфейс внутри игры не входят в начальный предложенный объём.
