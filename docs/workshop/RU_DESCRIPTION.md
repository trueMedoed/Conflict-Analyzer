# Conflict Analyzer — черновик Workshop (русский перевод)

Служебная заметка: неопубликованный черновик для внутренней сверки. Анализ и экспорт ниже только планируются. Блоки Summary и Description используют обычный текст для копирования. По умолчанию для Workshop предназначена английская версия; обновлять обе версии нужно вместе после проверки.

## Summary

Планируемый помощник Workbench для изучения сценария Conflict: покажет, какие группы ИИ, источники припасов, стартовые базы и точки появления машин настроены в его мире. В начальном каркасе функции анализа пока недоступны.

## Description

Conflict Analyzer планируется как помощник автору сценария: он будет собирать понятный обзор мира Conflict, чтобы не вести все таблицы вручную.

Текущий статус
• Созданы только начальный addon-проект и документация разработки.
• Команда анализа мира и экспорт отчёта ещё не реализованы.
• Этот черновик не описывает выпущенный или проверенный инструмент анализа.

Планируемые возможности
• Точки появления ИИ, типы групп, фракция, состав и число бойцов, с отдельным отображением случайных вариантов и вероятностей появления.
• Точки с припасами и число хранилищ, начальные припасы, вместимость, количество и интервал пополнения.
• Кандидаты стартовых HQ, их местоположение, исходные припасы и настройки их генерации.
• Точки появления машин, местоположение, допустимые варианты техники и доступные настройки спавна или повторного появления.
• Читаемый отчёт с источниками данных и предупреждениями о неполной информации.

Планируемое использование
1. Открыть addon-проект в Arma Reforger Workbench.
2. Выбрать мир Conflict после реализации команды анализа.
3. Выгрузить отчёт в отдельный каталог.

Планируемая корневая категория меню — [ME] Conflict Analyzer. Сейчас команды нет.

Ограничения
• Одного чтения .ent недостаточно: нужно разрешать связанные слои, родительские миры, prefab и конфигурационные ресурсы.
• Настроенные кандидаты и максимальные возможные количества не гарантируют конкретный спавн в игровой сессии.
• Значения зависят от версии мира и игры. Недоступные ресурсы должны обозначаться как неизвестные, а не ноль.
• Runtime-диагностика и интерфейс внутри игры не входят в начальный предложенный объём.
