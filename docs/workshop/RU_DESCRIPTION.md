# Conflict Analyzer — черновик Workshop (русский перевод)

Служебная заметка: неопубликованный черновик для внутренней сверки. Диагностика source реализована; полный игровой отчёт ещё планируется. Блоки Summary и Description используют обычный текст для копирования. По умолчанию для Workshop предназначена английская версия; обновлять обе версии нужно вместе после проверки.

## Summary

Помощник Workbench для исследования мира Conflict. Первый прототип выгружает частичную диагностику источников; полные отчёты по ИИ, припасам, стартовым базам и машинам ещё разрабатываются.

## Description

Conflict Analyzer помогает автору сценария исследовать конфигурацию мира Conflict. Он развивается в инструмент сбора понятных отчётов, чтобы не вести все таблицы вручную.

Текущий статус
• Команда диагностики World Editor читает выбранные source-сущности, поля компонентов, слои, ссылки на prefab и мировые позиции в частичный JSON.
• Проверена на CTI_Campaign_HQC_Eden.ent в Arma Reforger / Workbench 1.8.0.13.
• Скрипт в репозитории строит из диагностического JSON частичный архивный отчёт по 18 базам-источникам припасов: настроенное пополнение за цикл, интервал в минутах и происхождение полей.
• Отдельная команда баз-источников теперь выгружает только выбранный компонент и четыре поля. Скрипт подготовки сохраняет Harbors.json рядом с генерируемой таблицей; общий data.json служит индексом разделов.
• Добавлена команда исследования хранилищ выбранной базы. Для аэропорта Everon раскрыты две композиции и пять физических контейнеров, всего 4000 припасов настроенной вместимости; виртуальные представления исключены из суммы. Следующий пакетный обход охватывает все 18 баз-источников; runtime-принадлежность ресурсной сети ещё не проверена.
• Добавлен столбец вместимости для всех 18 баз-источников: 49 уникальных физических контейнеров, 15 определённых вместимостей вложенных хранилищ и три случая unknown. Доход сохраняет прежнее проверенное время чтения; отдельно расположенные склады не приписываются базе по расстоянию.
• Добавлены целевая инвентаризация контейнеров мира и отчёт OtherContainers: 568 остальных физических слотов в 129 группах, настроенная вместимость 190700. Прежние контейнеры баз исключены после проверки идентичности; 129 остальных виртуальных представлений сохранены отдельно. Принадлежность отдельных складов и runtime-спавн ещё не проверены.
• OtherContainers теперь группирует 568 физических слотов в 124 строки корневых родителей; индивидуальные записи и разные экземпляры prefab сохранены в JSON.
• Сопоставление в радиусе 350 м использует населённые пункты, острова и холмы с равным приоритетом первого этапа, затем Name Generic для остатка: 62 объекта первого этапа, 61 второго и 19 без группы. Все исходные объекты / подписи сохранены в JSON; сопоставление идёт по позиции подписи, а не границам местности.
• Locations Markdown упрощён до 31 списка локаций с объектами; типы, ID локаций и все 170 исходных подписей сохранены в JSON.
• Locations оформлен для ручной сверки групп мира: позиции локаций в заголовках, позиции объектов и расстояния в списках; в конце единого отчёта — категория «Объекты без группы» с 19 оставшимися объектами. Отдельная таблица UngroupedObjects больше не создаётся.
• OtherContainers и Harbors объединены в один отчёт: сначала 25 групп контейнеров и 15 объектов без группы, в конце Harbors — 15 групп и 4 базы без группы. Значения / состав / пополнение сохранены; повторные связи не увеличивают итоги.
• Полные игровые отчёты и сравнение версий ещё не реализованы. Это неопубликованный прототип.

Планируемые возможности
• Точки появления ИИ, типы групп, фракция, состав и число бойцов, с отдельным отображением случайных вариантов и вероятностей появления.
• Точки с припасами и число хранилищ, начальные припасы, вместимость, количество и интервал пополнения.
• Кандидаты стартовых HQ, их местоположение, исходные припасы и настройки их генерации.
• Точки появления машин, местоположение, допустимые варианты техники и доступные настройки спавна или повторного появления.
• Читаемый отчёт с источниками данных и предупреждениями о неполной информации.

Текущее использование диагностики
1. Открыть addon-проект в Arma Reforger Workbench.
2. Открыть сохранённый мир Conflict в World Editor.
3. Выполнить Export world source diagnostics в [ME] Conflict Analyzer / Diagnostics. В репозитории также описан проверенный CLI-путь через журнал Workbench.

Диагностика читает текущее состояние редактора и не сохраняет исходный мир. Файловая выгрузка использует отдельный каталог; прямой экспорт через FileIO ещё требует интерактивной проверки.

Ограничения
• Одного чтения .ent недостаточно: нужно разрешать связанные слои, родительские миры, prefab и конфигурационные ресурсы.
• Настроенные кандидаты и максимальные возможные количества не гарантируют конкретный спавн в игровой сессии.
• Значения зависят от версии мира и игры. Недоступные ресурсы должны обозначаться как неизвестные, а не ноль.
• Полное разрешение объектных конфигов и каталогов фракций ещё не готово; команда вместимости читает только необходимые настройки контейнеров выбранной базы. Найденные компоненты не являются игровыми итогами или числом бойцов.
• Runtime-диагностика и интерфейс внутри игры не входят в начальный предложенный объём.
