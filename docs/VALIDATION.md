## Диагностический прогон HQC Everon

Проверено 05.10.2026 на **Arma Reforger / Workbench 1.8.0.13**, сборка engine **192142**. Плагин компилируется в `WorkbenchGame`; World Editor открывает ресурс установленной базовой игры `$ArmaReforger:worlds/MP/CTI_Campaign_HQC_Eden.ent`.

Успешные журналы:

- `C:\Users\Phil\Documents\My Games\ArmaReforgerWorkbench\logs\logs_2026-10-05_14-17-44\console.log`.
- `C:\Users\Phil\Documents\My Games\ArmaReforgerWorkbench\logs\logs_2026-10-05_14-18-57\console.log` — повтор в новом процессе.

Оба запуска выполнены с `-wbModule=WorldEditor -run -exitAfterInit -plugin=ME_CA_WorldDiagnosticsPlugin -ME_CA_World=worlds/MP/CTI_Campaign_HQC_Eden.ent -ME_CA_LogJson=1`. Пути проекта и `-addonsDir` совпадают с установкой выше; полный пример находится в [SOURCE_DIAGNOSTICS.md](SOURCE_DIAGNOSTICS.md).

Результаты:

- Обе сцены загружены: `subsceneCount=2`; editor source до и после — **1 240 201**. С учётом обхода дочерних prefab source посещено **1 430 800** уникальных источников; в диагностике отобрано **3 153** записи.
- Все 3 153 позиции разрешены и сверены с `IEntity.GetOrigin()` независимым расчётом матриц родителей. **2 204** записи имеют повёрнутого родителя; **113** учитывают `RELATIVE_Y` корня и высоту поверхности. Ошибок выше **0,02 м** нет; максимум **0,000244 м**.
- Среди отобранных записей нет родителей с масштабом, отличным от единицы. Поддержка масштаба в коде не заменяет отдельную проверку этого случая.
- После исключения только `generatedAtUTC` оба JSON совпадают полностью, включая порядок, поля, позиции и editor source ID. Это подтверждает повторяемость двух запусков на одинаковых ресурсах, а не устойчивость ID между версиями игры.
- JSON собран `tools/Convert-DiagnosticsLog.ps1`: совпали объявленная длина и полученные фрагменты, синтаксис корректен, число записей совпадает с метаданными. SHA-256 первого файла: `EB33930D60A912D9FF2AACDBD32218D421911665C0E23FEE3B07229074D52233`.
- Проверка конвертера на существующем файле завершилась отказом; SHA-256 файла до и после совпал. Незавершённый журнал отклонён, выходной файл не создан.
- Синтаксис PowerShell-конвертера проверен парсером; все 17 относительных Markdown-ссылок ведут к существующим файлам. Диагностические ключи `subscene/layer/sourceId` уникальны; предупреждений о неоднозначных ID нет. `exports/` исключён из Git, постоянные каталоги `snapshots/` и `changes/` не исключены.
- В обоих успешных журналах нет `SCRIPT (E)` или `ENGINE (E)`. При завершении остаётся базовый блок Resource leaks из 25 строк; он не скрывается из результата проверки.
- Проверочные процессы завершились автоматически. Ранее зависшие на FileIO или избыточном выводе собственные процессы закрывались только после сверки PID, пути и времени запуска; пользовательский Workbench не закрывался.

Исходный мир находится в пакетах базовой игры. Код плагина не вызывает создание/удаление сущностей, изменение source или сохранение мира. Количество editor source и путь мира до/после чтения проверены. Проверка сохранённых файлов и всех свойств сцены на специальном изменяемом fixture ещё нужна; совпадение счётчиков само по себе не является полной проверкой неизменности.

При подготовке исправлены ошибочный вызов map API, формат CLI-параметров, расчёт координат и обрезка фрагментов размером 8192. Итоговый протокол использует фрагменты по 4096 и проверку целостности. Прямой FileIO-путь остановился на запросе авторизации Workbench; разрешения не менялись. Успешный режим журнала не вызывает FileIO из скрипта. Прямой экспорт из меню остаётся непроверенным.

Наблюдения по игровым настройкам приведены в [отчёте эксперимента](experiments/HQC_Eden_1.8.0.13.md). Полные каталоги ИИ, размеры групп, объектные конфиги ресурсов, вместимость, единицы остальных настроек, полный отчёт четырёх разделов и сравнение версий не проверены и не объявлены реализованными. - Повторная обработка того же входа дала побайтово одинаковые `data.json`, `world.json`, `Supplies.md` и `Supplies/Harbors.md`.
- Попытка записи в существующий каталог отклонена, SHA-256 `data.json` сохранился. Нечисловое обязательное поле отклонено до создания выходного каталога.
