# Снимки данных по версиям игры

Утверждённая иерархия: `<game-version>/worlds/<scenario-key>/`.

В каталоге версии будет `manifest.json`, а в каталоге сценария — `world.json`, `data.json` и таблицы `AI-Groups.md`, `Supplies.md`, `Starting-Bases.md`, `Vehicle-Spawns.md`.

Этот каталог хранится в Git. Сейчас здесь только описание структуры: анализатор ещё не реализован и фактические снимки не собраны. Каталоги версий создаются после анализа и проверки данных.

Временная подготовка результатов выполняется в игнорируемом `exports/`. Опубликованные снимки сохраняются; исправленная пересборка должна быть отдельной ревизией.

Правила метаданных, идентификаторов и сравнения: [docs/DATA_LAYOUT.md](../docs/DATA_LAYOUT.md).
