# Припасы по приоритетам

Текущая ревизия **r0033**: [единая таблица](Supplies/OtherContainers.md), [объекты](Locations.md), [граф](revisions/r0033/Locations.json), [индекс](revisions/r0033/data.json), [метаданные](revisions/r0033/world.json).

Склады припасов → контрольные точки → Harbors → города / деревни → остальные объекты → нераспознанные. Сначала локации маркеров определяются в 350 м, затем хранилища в 100 м исключаются из последующих этапов. У каждой контрольной точки командный пункт и остальные хранилища собраны в одну таблицу. Для командного пункта показано 1000 / 0 и состав для 5 / 6 контейнеров. Ноль — целевой запас после действия префаба хранилища; отложенная инициализация всей ресурсной сети базы и фактический игровой запас учитываются отдельно. У складов показаны локации и физические контейнеры; координаты и настройки компонентов маркеров сохранены только в JSON. Их влияние на игру отложено для отдельного исследования в TODO.

Координаты локаций и объектов округлены до трёх знаков после точки, X Y Z через пробел для Workbench. Источники, физическая вместимость и состав сохранены; группировка пересчитана по новому приоритету.
