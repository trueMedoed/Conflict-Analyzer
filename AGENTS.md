## Назначение и текущий этап

Помощник для исследования миров Conflict в Arma Reforger. Пользователь утвердил название **Conflict Analyzer** и режим **помощника Workbench**: читать выбранный мир и формировать отчёт по аналогии с таблицами `Conflict/Constants`.

Реализованы широкая диагностика editor source и отдельный целевой экспорт баз-источников припасов, проверенные на HQC Everon 1.8.0.13. Ревизия `r0002` использует schemaVersion 2: 18 записей находятся в `Supplies/Harbors.json`, рядом строится Markdown, общий `data.json` служит индексом. Объём задачи и критерии готовности находятся в `TODO.md`; запуск целевой команды — в `docs/SUPPLY_SOURCES.md`, диагностики — в `docs/SOURCE_DIAGNOSTICS.md`.

## Реализация

- Не ограничивайтесь текстом `.ent`: учитывайте слои, родительский мир, prefab, конфиги и переопределения. Недоступные зависимости обозначайте явно.
- Следуйте утверждённому [алгоритму отбора и экспорта](docs/EXPORT_ALGORITHM.md): читать зависимости, включая Eden, но сохранять только объекты нужных разделов и явный список полей. - Обычный экспорт должен сразу распределять нормализованные записи по JSON рядом с соответствующими Markdown-таблицами; общий `data.json` нового формата — индекс, без дублирования записей. Широкий дамп всех доступных полей оставляйте отдельным явно выбранным режимом диагностики.

- Вместимость выбранной базы раскрывайте по иерархии база → хранилище → физический контейнер через `SCR_ResourceComponent.m_aContainers`. Для каждого сохраняйте `m_fResourceValueMax` отдельно от `m_fResourceValueCurrent`, ID, prefab и происхождение.
